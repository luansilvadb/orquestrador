# Orquestrador v0.1.33

## Resumo

A v0.1.33 corrige o contador de alterações do Git na coluna de ícones: com mais de 99 arquivos alterados, ele passa a mostrar o número real em vez de “99+”. Não há outra mudança.

## Novidades

Esta versão não traz uma novidade funcional. O contador do botão do Git, no canto inferior direito do ícone, deixa de limitar a exibição a “99+”. Com 146 arquivos alterados, por exemplo, mostra 146. Até 99 arquivos, nada muda.

## Melhorias e correções

- O contador de alterações do Git na coluna de ícones mostra a contagem completa quando há mais de 99 arquivos alterados. Antes, qualquer valor acima de 99 aparecia como “99+”, o que escondia o tamanho real da mudança em repositórios com muitos arquivos modificados.

## Impacto da atualização

Não há migração de dados nem de configuração. A atualização troca os arquivos do programa; as configurações e os arquivos dos projetos permanecem no lugar. A única diferença visível é o número exibido no contador do Git quando passa de 99 alterações.

## Requisitos e limitações

O instalador desta versão é para Windows de 64 bits. Git precisa estar disponível para o recurso correspondente. O contador não tem mais teto de exibição, então números de três dígitos ou mais ocupam mais largura no ícone. A atualização automática depende de conexão com a internet e de um instalador assinado.

## Instalação

Baixe [Orquestrador_0.1.33_x64-setup.exe](https://github.com/luansilvadb/orquestrador/releases/download/v0.1.33/Orquestrador_0.1.33_x64-setup.exe) na página da [release v0.1.33](https://github.com/luansilvadb/orquestrador/releases/tag/v0.1.33). Quem já tem o app recebe a atualização ao abri-lo: o atualizador consulta a release estável, baixa o instalador, valida a assinatura, instala e reabre o programa.
