# Orquestrador v0.2.6

## Resumo

A v0.2.6 faz `claude` e `codex` funcionarem em qualquer terminal novo. Na abertura, o portão põe no PATH do usuário a pasta do CLI quando o instalador a deixou de fora.

## Novidades

Esta versão não traz funcionalidade nova: é uma correção do portão de abertura, descrita em Melhorias e correções.

## Melhorias e correções

- **Pasta do CLI no PATH do usuário.** O instalador oficial do Claude Code (`irm https://claude.ai/install.ps1 | iex`) instala em `%USERPROFILE%\.local\bin`, avisa que a pasta não está no PATH e não a adiciona. Por isso `claude` dava CommandNotFoundException no terminal, embora o app funcionasse pelo caminho absoluto. Agora, na abertura, o portão acrescenta a pasta do `claude.exe` e do `codex.exe` a `HKCU\Environment\Path` quando ela não está lá.
- **Gravação segura.** O valor é gravado preservando os `%vars%` e o tipo REG_EXPAND_SZ. A pasta não é duplicada: a comparação ignora caixa e barra final.
- **Ordem e falha.** A gravação só acontece depois do `update` com sucesso. Se ela falhar, o portão bloqueia o uso com uma mensagem que diz a pasta e o motivo.

## Impacto da atualização

A v0.2.5 recebe a v0.2.6 pelo fluxo de atualização existente. Quem já tem o CLI fora do PATH é corrigido na próxima abertura do app. As outras janelas são avisadas da mudança (WM_SETTINGCHANGE), mas só terminais abertos depois disso veem o PATH novo; terminais já abertos precisam ser reabertos.

## Requisitos e limitações

Windows de 64 bits com Direct3D 11, por GPU ou WARP, e Claude Code ou Codex instalado para usar o orquestrador. A correção altera só o PATH do usuário, não o do sistema.

## Instalação

Após a publicação, baixe [Orquestrador_0.2.6_x64-setup.exe](https://github.com/luansilvadb/orquestrador/releases/download/v0.2.6/Orquestrador_0.2.6_x64-setup.exe) na página da [release v0.2.6](https://github.com/luansilvadb/orquestrador/releases/tag/v0.2.6). Quem já tem a v0.2.5 recebe a atualização ao abrir o app, que baixa e verifica o instalador, instala e reabre o programa.
