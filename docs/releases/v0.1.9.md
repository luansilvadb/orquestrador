# Orquestrador v0.1.9

## Resumo

A v0.1.9 é uma versão de manutenção: limpa o código da v0.1.8, sem funcionalidade nova. Saem comandos internos que o app não usava mais, partes repetidas passam a ser compartilhadas, e as três faixas de abas passam a seguir uma regra só para mostrar a aba ativa. Quem usa a v0.1.8 recebe a atualização ao abrir o app, e para isso precisa de internet.

## Novidades

Esta versão não traz funcionalidade nova. O editor em grupos, o Ctrl+P, o grafo e o histórico do Git e a pesquisa continuam como na v0.1.8.

## Melhorias e correções

**Faixas de abas com a mesma regra.** O editor, o painel do Orquestrador e o painel Terminal usam agora a mesma função para manter a aba ativa visível e a mesma rolagem pela roda do mouse. As medidas são feitas com subpixel, e a borda da aba é arredondada para não ficar cortada nem por fração de pixel. A faixa só volta para o começo da aba quando a aba é maior que a faixa.

**Grupo vazio sem texto de ajuda.** Um grupo do editor sem abas não mostra mais a frase "Abra um arquivo, um diff ou um commit para ver aqui.". A área abaixo da faixa fica em branco.

**Erros do Git mais completos.** Listar arquivos, ler o conteúdo de um arquivo no Git, o diff por bloco e os conflitos de merge passam pelo mesmo executor dos outros comandos Git. Quando falham, a mensagem traz a saída de erro e a saída normal do Git, como nas outras operações.

**Diálogos de arquivo unificados.** Renomear, Criar e Excluir na árvore de arquivos usam um diálogo comum. O comportamento é o mesmo: enquanto o pedido roda, Esc, clique fora e Cancelar ficam bloqueados, e o botão de confirmar mostra o andamento.

**Código removido.** Saem os comandos internos `write_file`, `delete_file`, `copy_file`, `paste_files` e `git_diff`, substituídos na v0.1.8 por `write_file_checked`, `delete_files`, `copy_files`, `paste_files_detailed` e `git_review_diff`. O editor já gravava só pelo `write_file_checked`, que só grava se o arquivo não mudou desde a leitura. A lista de abas recentes, que nenhum atalho usava, também saiu.

**Checagens.** Os checks em Node passam a usar o `node:test`, os checks de interface compartilham o mesmo roteiro, e o teste de lote do backend apaga a pasta temporária mesmo quando falha.

## Impacto da atualização

- Abas, rascunhos, cursor e layout salvos pela v0.1.8 carregam como antes: o formato da recuperação não mudou. O campo da lista de abas recentes, se existir no estado salvo, é ignorado.
- A configuração não muda.
- Os atalhos não mudam: Ctrl+\`, Ctrl+Shift+F, F4, Shift+F4 e Ctrl+P funcionam como na v0.1.8.

## Requisitos e limitações

- Windows de 64 bits, com WebView2. O instalador é NSIS por usuário, sem privilégio de administrador.
- Git instalado e disponível no PATH, usado pelo painel Git, pela pesquisa e pela abertura rápida. A pasta aberta no app precisa ser um repositório Git.
- Os CLIs `claude` e `codex` no PATH, instalados e configurados na máquina. Você precisa apenas dos CLIs que for usar.
- A atualização automática exige internet. Sem ela, o uso fica bloqueado até a atualização dar certo.
- A pesquisa devolve no máximo 2000 linhas casadas. Arquivos acima de 1 MiB e binários ficam fora da busca.
- O grafo e o histórico do Git mostram 50 commits por página, e o restante vem com Carregar mais.
- Renomear funciona com um item por vez. Recortar, copiar e excluir aceitam vários.
- O descarte pelo diff vale só para alteração não preparada de arquivo rastreado. Ele é recusado com executor trabalhando, com rascunho aberto daquele arquivo, ou se o conteúdo mudou desde a leitura.
- Rascunhos ficam no navegador do app, e a limpeza dos dados do app os apaga.
- Terminais, executores e conversas ainda não são restaurados ao reabrir o app.
- Excluir manda o item para a Lixeira do Windows. Não há exclusão definitiva.
- O instalador é assinado para o atualizador, não com um certificado de código do Windows. O SmartScreen pode mostrar um aviso na primeira instalação.

## Instalação

- Versão nova, sem o app instalado: baixe o instalador [Orquestrador_0.1.9_x64-setup.exe](https://github.com/luansilvadb/orquestrador/releases/download/v0.1.9/Orquestrador_0.1.9_x64-setup.exe). A página da release está em [Orquestrador v0.1.9](https://github.com/luansilvadb/orquestrador/releases/tag/v0.1.9).
- Já instalado (v0.1.8): abra o app. Ele baixa a v0.1.9 sozinho, valida a assinatura, instala em modo silencioso e reabre na versão nova.
- A release traz também `latest.json` e o `.sig` do instalador, usados pelo atualizador.

## Comparação com a versão anterior

| Área | v0.1.8 | v0.1.9 |
| --- | --- | --- |
| Faixas de abas | Cada faixa com o próprio cálculo para mostrar a aba ativa | Uma regra só, com medida em subpixel, nas três faixas |
| Grupo vazio do editor | Texto de ajuda para abrir um arquivo | Área em branco |
| Erros do Git | Algumas operações mostravam só a saída de erro | Todas mostram a saída de erro e a saída normal |
| Comandos internos | Comandos antigos de gravar, excluir, copiar, colar e diff ainda presentes | Removidos; ficam só as versões usadas pelo app |
| Checagens | Saída própria em cada script | `node:test` nos checks puros e roteiro comum nos checks de interface |

Diferença completa de código: [v0.1.8...v0.1.9](https://github.com/luansilvadb/orquestrador/compare/v0.1.8...v0.1.9).
