# Orquestrador v0.1.18

## Resumo

A v0.1.18 é uma versão de polimento: o comparador do Git mostra arquivo novo numa coluna só, o editor sem abas passa a mostrar os atalhos principais do app e os terminais ficam alinhados com o texto dos cabeçalhos.

## Novidades

**Arquivo novo numa coluna só.** No comparador do Git, um arquivo que não tem original (não rastreado, preparado como novo ou criado num commit) aparece numa coluna só, com as linhas acrescentadas desde a linha 1. Não há divisor nem a troca entre Lado a lado e Unificado, porque não há nada do outro lado para comparar. A faixa de visão geral, a navegação com F8 e Shift+F8 e as ações da barra (Preparar arquivo, Tirar bloco do preparo) continuam como antes.

**Atalhos no editor vazio.** Um grupo do editor sem abas mostra, no centro, os atalhos que já existem no app, como a marca d'água do editor vazio do VS Code: Abrir arquivo (Ctrl+P), Pesquisar nos arquivos (Ctrl+Shift+F), Alternar o terminal (Ctrl+`) e Nova issue (Ctrl+Shift+I). É só texto, sem clique.

## Melhorias e correções

- O texto dos terminais (o do Orquestrador e os shells do painel Terminal) passa a começar a 12 px da borda (antes, 8 px), na mesma coluna do texto dos cabeçalhos.
- A documentação da faixa de abas dos arquivos voltou a bater com o código (30 px, nas medidas do Antigravity).
- Ficam registradas no repositório as críticas de design da tela Issues e da tela Git, que guiam os próximos ajustes de interface.

## Impacto da atualização

Nada muda em configuração, projetos, issues ou dados do app. Quem vem da v0.1.17 só nota a mudança visual: o arquivo novo aparece numa coluna, o editor sem abas mostra os atalhos e o texto dos terminais fica um pouco mais afastado da borda. A escolha entre Lado a lado e Unificado continua valendo para os diffs de arquivos que já existiam.

## Requisitos e limitações

- Windows de 64 bits com WebView2; o instalador NSIS é por usuário e não exige privilégio de administrador.
- Git no PATH é necessário para os recursos do painel Git.
- Os CLIs `claude` e `codex` precisam estar no PATH quando forem usados.
- O arquivo novo é reconhecido pelo cabeçalho `new file mode` do patch do Git; um arquivo acima de 1 MiB continua sem caber no comparador, que diz que o diff é grande demais.
- A atualização automática requer internet; se a verificação, o download ou a instalação falhar, o uso fica bloqueado até tentar novamente.
- O instalador é assinado para o atualizador, não com certificado de código do Windows; o SmartScreen pode mostrar um aviso na primeira instalação.

## Instalação

- Para instalar, baixe [Orquestrador_0.1.18_x64-setup.exe](https://github.com/luansilvadb/orquestrador/releases/download/v0.1.18/Orquestrador_0.1.18_x64-setup.exe) na página da release [Orquestrador v0.1.18](https://github.com/luansilvadb/orquestrador/releases/tag/v0.1.18).
- Quem já tem o app recebe a atualização automaticamente ao abrir: o instalador é baixado, a assinatura é validada, a instalação é silenciosa e o app reabre na versão nova.
- A release também traz o `latest.json` e o `.sig` do instalador, usados pelo atualizador.
