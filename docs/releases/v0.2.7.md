# Orquestrador v0.2.7

## Resumo

A v0.2.7 deixa de bloquear o app quando o portão não consegue pôr a pasta do CLI no PATH do usuário. O app usa o caminho absoluto do CLI, então a falha vira um aviso, e a gravação passa a acontecer antes do `update` do CLI.

## Novidades

Esta versão não traz funcionalidade nova: é uma correção do portão de abertura, descrita em Melhorias e correções.

## Melhorias e correções

- **Falha ao gravar o PATH vira aviso.** Se o portão não consegue acrescentar a pasta do CLI a `HKCU\Environment\Path`, a tela de abertura mostra um aviso com o CLI, a pasta, o motivo e como resolver à mão. Um botão Continuar libera o uso do app.
- **Gravação antes do `update`.** A pasta do CLI vai para o PATH logo depois de o portão ler a versão do CLI, antes do `claude update` ou `codex update`. Assim, um `update` que falha não impede a correção do PATH. O erro do `update` continua bloqueando o uso.

## Impacto da atualização

A v0.2.6 recebe a v0.2.7 pelo fluxo de atualização existente. Quem ficava preso na tela de abertura por falha ao gravar o PATH passa a ver o aviso e pode continuar. Quem tinha o `update` do CLI falhando passa a ter a pasta no PATH mesmo assim, embora o portão siga bloqueando até o `update` funcionar.

## Requisitos e limitações

Windows de 64 bits com Direct3D 11, por GPU ou WARP, e Claude Code ou Codex instalado para usar o orquestrador. A correção altera só o PATH do usuário, não o do sistema. Terminais abertos dentro de um app que já rodava antes da gravação, como o terminal integrado do VS Code, mantêm o PATH antigo até esse app ser reiniciado. O terminal do próprio orquestrador relê o PATH a cada terminal aberto. Detalhes em [atualização e release](https://github.com/luansilvadb/orquestrador/blob/v0.2.7/docs/atualizacao.md).

## Instalação

Após a publicação, baixe [Orquestrador_0.2.7_x64-setup.exe](https://github.com/luansilvadb/orquestrador/releases/download/v0.2.7/Orquestrador_0.2.7_x64-setup.exe) na página da [release v0.2.7](https://github.com/luansilvadb/orquestrador/releases/tag/v0.2.7). Quem já tem a v0.2.6 recebe a atualização ao abrir o app, que baixa e verifica o instalador, instala e reabre o programa.

## Comparação com a versão anterior

| Área | v0.2.6 | v0.2.7 |
| --- | --- | --- |
| Falha ao gravar o PATH | Portão bloqueia com mensagem | Aviso com CLI, pasta, motivo e solução manual; botão Continuar libera o uso |
| Momento da gravação | Só depois do `update` do CLI com sucesso | Logo depois de ler a versão, antes do `update` |
| `update` do CLI com falha | Bloqueia e o PATH fica sem a pasta | Bloqueia, mas o PATH já foi corrigido |

Diferença completa na [comparação entre v0.2.6 e v0.2.7](https://github.com/luansilvadb/orquestrador/compare/v0.2.6...v0.2.7).
